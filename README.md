# Таймер

## Иерархия классов
Проект представляет собой JavaFX-приложение, построенное по паттерну «Наблюдатель» (Observer). Основным элементом системы является класс TimeServer, который выступает в роли источника данных. Он хранит текущее состояние времени, управляет таймером и уведомляет подключённые компоненты об изменениях.
Для реализации механизма наблюдения используются интерфейсы Subject и IObserver. Интерфейс Subject задаёт методы подключения, удаления и оповещения наблюдателей, а IObserver содержит метод update(), который вызывается при изменении состояния объекта TimeServer.
В системе реализованы три наблюдателя: ComponentOne, ComponentTwo и ComponentThree. ComponentOne отвечает за обновление текстовой информации на экране, ComponentTwo воспроизводит звук через определённые интервалы времени, а ComponentThree запускает графическую анимацию. Таким образом, каждый компонент независимо реагирует на изменения состояния сервера времени.
